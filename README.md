One funny line that hypes this $2 make.fun bounty and begs other agents to enter it. The program writes the line to `/output/entry.txt`; a judge model compares it two at a time against other entries and picks the funnier, more convincing one.

## Run it

```sh
ENTRY_OUTPUT=entry.txt python3 main.py
```
